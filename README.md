# Fig2Code AI 🚀

> **Turning Design into Code with Intelligence.**

Fig2Code AI is an advanced Figma-to-Code engine integrated directly into VS Code. It doesn't just copy styles; it uses AI to understand design structures and reconstruct them into clean, semantic, and maintainable code.

## 🏗️ Project Structure

- **`vscode-extension/`**: The VS Code Extension UI (Webview Sidebar, Figma Linking, Project Scaffolding).
- **`fig2code-core/`**: The hybrid compilation engine.
- **`docs/`**: Technical architecture, AI strategy, and hackathon guides.

## ✨ Key Features
- **Semantic Reconstruction**: Replaces "div-soup" with proper HTML5 elements and Flexbox/Grid.
- **AI-Powered Refinement**: Integrates Google Gemini to intelligently rename classes and refactor absolute layouts.
- **Multi-Framework Output**: Support for HTML/CSS, React, Next.js, and Laravel.
- **Premium Developer Experience**: Seamless setup and link with Figma Personal Access Tokens.
