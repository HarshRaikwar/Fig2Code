# Fig2Code AI 🚀 (Hackathon Pro Edition)

> **The Industry Standard for Turning Design into Production-Ready Code.**

Fig2Code AI is a high-performance Figma-to-Code engine that leverages Google Gemini AI to bridge the gap between design and development. It doesn't just copy styles; it understands the *intent* of your design.

## 🌟 Elite Features

- **🧠 AI Semantic Refinement**: Uses Gemini 1.5 Flash to refactor raw Figma data into semantic HTML5 or high-quality React components. No more "div-soup."
- **🏗️ Multi-Framework Scaffolding**: Generates full, production-ready project structures:
  - **React + Tailwind CSS**: Complete with `tailwind.config.js` and component subfolders.
  - **Semantic HTML5/CSS**: Clean, responsive, and BEM-compliant.
  - *Next.js & Laravel (Coming Soon)*
- **💎 Premium DevX**: Integrated directly into VS Code with a glassmorphism sidebar, live code preview, and one-click workspace application.
- **⚡ High Performance**: Fast Figma API integration with efficient Intermediate Representation (IR) mapping.

## 🚀 How it Works

1. **Link**: Connect your Figma Token and Gemini API Key in the settings ⚙️.
2. **Convert**: Paste any Figma URL and choose your destination framework.
3. **Refine**: Watch AI refactor absolute layouts into clean Flexbox/Grid systems.
4. **Deploy**: Click "Apply" to scaffold a full project folder in your workspace instantly.

## 🏗️ Project Structure

- **`vscode-extension/`**: The premium UI and VS Code integration logic.
- **`fig2code-core/`**: The hybrid compilation engine (shared IR logic).
- **`docs/`**: Setup guides, AI strategies, and technical architecture.
